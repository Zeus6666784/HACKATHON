# Future Scope - CareConnect Maharashtra

These features are intentionally **OUT OF SCOPE** for the hackathon implementation to ensure the core referral loop is stable.

## 1. Ecosystem Integration
- **ABDM Integration**: Linking with the Ayushman Bharat Digital Mission for unified health IDs.
- **FHIR Standards**: Implementing HL7 FHIR for interoperable clinical data exchange.
- **Diagnostic Network**: Direct API integration with labs to auto-update `DIAGNOSTICS` state.

## 2. Advanced AI & Analytics
- **Predictive Leakage**: AI that predicts which patients are most likely to be "Lost-to-follow-up" based on distance and demographics.
- **Automated Triage-to-Bed**: Integrating with real-time bed availability APIs.
- **Advanced NLP**: Support for more regional dialects beyond standard Marathi/Hindi.

## 3. Communication Channels
- **SMS/WhatsApp Notifications**: Moving beyond in-app alerts to reach patients and workers via mobile messaging.
- **Automated Voice Reminders**: Using TTS for medication and follow-up reminders.

## 4. Scalability & Infrastructure
- **Large-scale Sync**: Implementing a more robust offline-first architecture using PWA and IndexedDB for extremely remote areas.
- **Multi-District Expansion**: Scaling the facility dataset to cover all districts of Maharashtra.
- **Ambulance Integration**: Real-time tracking of referral transport from PHC to Hospital.

## 5. Governance
- **Patient Portal**: Allowing patients to view their own referral status and reminders.
- **Government Dashboard**: High-level analytics for state health officials to track district-wise closure rates.
