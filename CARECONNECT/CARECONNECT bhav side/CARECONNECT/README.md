# CareConnect Maharashtra
A referral-continuity layer for rural healthcare.

## Project Structure
- `client/`: React + Vite + TypeScript frontend.
- `server/`: Node + Express + TypeScript backend.
- `docs/`: Complete project documentation.

## Quick Start
1. Clone the repo.
2. Setup environment variables using `.env.example`.
3. Install dependencies in both `client/` and `server/`.
4. Start MongoDB.
5. Run `npm run dev` in both directories.

## Core USP
Referral Closure: Tracking the patient journey from initial triage to final healthcare outcome.
